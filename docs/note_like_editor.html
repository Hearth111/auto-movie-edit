note風のインライン編集メニュー

テキストを選択すると、選択位置に合わせて太字・引用・見出し・箇条書きなどのメニューがポップアップします。

noteのような書き味を再現

文章の一部をドラッグして選択すると、選択範囲のすぐそばにメニューが現れます。書きながら太字や斜体、引用の挿入をサッと切り替えられます。

引用は左に帯を引いたスタイル。本文から浮き立たせたい一節に使えます。

段落を整えるときは「見出し」や「箇条書き」を選んでください。もう一度同じボタンを押すと通常の段落に戻せます。

  • 太字・斜体・見出し・引用・箇条書きをサポート
  • 選択範囲に追従してポップアップ
  • 選択解除やフォーカス移動で自動的に隠れます
